
# 📚 Library Management System

A console-based Library Management System developed using C++. This application helps manage books, library members, and borrowing records through a simple menu-driven interface.

## 🌟 Project Overview

The Library Management System is designed to simplify basic library operations. It allows users to add books, register members, issue and return books, search for books, and maintain borrowing records.

The application uses Object-Oriented Programming (OOP) concepts and file handling to organise and store library information.

## ✨ Features

- **Add Books:** Add new books with unique IDs, titles, authors, and copy quantities.
- **Member Registration:** Register library members with unique IDs and names.
- **Display Books:** View all books and their available copies.
- **Display Members:** View registered library members.
- **Search Books:** Search for books by title or author.
- **Issue Books:** Issue available books to registered members.
- **Return Books:** Process book returns and update availability.
- **Borrowing History:** View issue and return records.
- **File Handling:** Store book, member, and borrowing information in text files.
- **Input Validation:** Handle invalid menu and numeric inputs.

## 🛠️ Technologies Used

- C++
- C++11
- Object-Oriented Programming
- Classes and Objects
- Vectors
- File Handling
- Standard Template Library (STL)

## 🧠 OOP Concepts Implemented

- **Classes and Objects:** Book, Member, BorrowRecord, and Library classes organise the application.
- **Encapsulation:** Library management operations and internal collections are kept private where appropriate.
- **Constructors:** Initialise book, member, and borrowing record objects.
- **Member Functions:** Separate functions handle each library operation.

## ▶️ How to Run

1. Open the source file in a C++ compiler.
2. Compile using a C++11-compatible compiler.
3. Run the generated program.
4. Follow the menu options to manage the library.

### Compile using GCC

```bash
g++ -std=c++11 main.cpp -o library
```

### Run

```bash
./library
```

On Windows, run:

```bash
library.exe
```

## 💾 Data Storage

The application uses text files to store:

- `books.txt` – Book details and available copies.
- `members.txt` – Registered member details.
- `borrow_records.txt` – Book issue and return records.

Data is loaded when the application starts and saved when library records are updated.

**Note:** File persistence depends on the compiler's runtime environment. The files are created in the program's working directory.
