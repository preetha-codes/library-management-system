01 / The concept
A little about Libra

A simpler way to keep a library in order.

Libra is a console-based Library Management System developed in C++. It brings essential library operations together in one straightforward, menu-driven application.

From adding books and registering members to managing borrowing records, the system demonstrates how programming fundamentals can solve everyday organisational problems.

Built with object-oriented programming and file handling, the project focuses on structured data, clear operations and reliable inventory updates.

02 / Capabilities

Everything in its right place.

A collection of practical tools for handling the everyday activities of a library.

01 — COLLECTION

Book management

Add books with unique identification numbers, titles, authors and copy quantities.

02 — MEMBERS

Member registration

Maintain a list of registered members with individual IDs and names.

03 — DISCOVERY

Book search

Locate books using their titles or author names with case-insensitive search.

04 — BORROWING

Book issuing

Issue available copies to registered members and update the inventory.

05 — RETURNS

Book returns

Process returns against active borrowing records and restore book availability.

06 — RECORDS

Borrowing history

Review issue and return records to track the status of borrowed books.
